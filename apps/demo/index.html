Images that arrive calmly.

lazy-ease loads each image at the size it is shown, keeps its placeholder in the first HTML and fades it in once, after decode.

npm i @lazy-ease/react
No layout shiftThe box has its size before a byte arrives.
One fade, after decodeNever a half-painted image.
The right size per slotThe srcset fits the width it is shown at.
Placeholders in the HTMLThumbHash, color or your own.

React

npm i @lazy-ease/react

<LazyEaseProvider>
  <Image src="/photos/lake.jpg" alt="Lake at dawn"
    width={320} height={240} srcWidth={2400} srcHeight={1800}
    placeholder="thumbhash:…" />
</LazyEaseProvider>

HTML and a script

npm i @lazy-ease/vanilla @lazy-ease/core

<script defer src="/assets/lazy-ease.min.js"></script>
<section data-le-auto>
  <span data-le style="aspect-ratio:4/3;background:#5b6c8f">
    <img alt="Lake at dawn" src="data:…" data-le-url="/_img/lake.jpg?w=640">
  </span>
</section>
